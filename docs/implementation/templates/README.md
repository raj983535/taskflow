# Implementation documentation templates

Use these templates to keep new implementation documents consistent and easy to follow.

- [Implementation guide template](implementation-guide-template.md) — required for meaningful features, business rules, technical concepts, and infrastructure changes.
- [Decision record template](decision-record-template.md) — for important architecture and engineering choices.

Templates are starting structures. Adapt or remove sections that genuinely do not apply, but keep the explanation of why, what, how, business logic, verification, and debugging wherever relevant.
