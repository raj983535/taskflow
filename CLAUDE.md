# Instructions for Claude-based coding agents

Read the repository-root [AGENTS.md](AGENTS.md) before planning or changing TaskFlow. It is the canonical project instruction file and applies to all coding agents.

Also read [the implementation documentation home](docs/implementation/README.md) and [the current project context](docs/implementation/PROJECT-CONTEXT.md).

Key rule: TaskFlow theory study and coding happen in parallel. Do not wait for the learner to complete a phase. Every meaningful feature, business rule, architectural choice, or new technical concept must be explained in a matching beginner-friendly document under docs/implementation/ and linked to relevant theory lessons. Code and required documentation are one deliverable.
