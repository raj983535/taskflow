# Application source area

This is the single home for TaskFlow application code when implementation is approved.

- [web/](web/README.md) — browser frontend using the agreed React + TypeScript direction.
- [api/](api/README.md) — backend HTTP API using the agreed Node.js + Express + TypeScript direction.
- [shared/](shared/README.md) — reserved for contracts/types genuinely shared between web and API.

This folder currently contains structure documentation only. It has no source code, package manifests, dependencies, or build configuration. Supporting libraries and tooling must be decided before implementation.
