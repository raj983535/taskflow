# Web frontend

Reserved for the TaskFlow browser application.

```text
web/
├── public/
├── src/
│   ├── app/
│   ├── components/
│   ├── features/
│   │   └── tasks/
│   ├── hooks/
│   ├── services/
│   ├── styles/
│   └── types/
└── tests/
```

Responsibilities include rendering the UI, navigation, task interactions, calling the API, and responsive accessible presentation.

This is a directory plan only. No React source, build tool configuration, package manifest, router, UI library, or test runner has been added.
